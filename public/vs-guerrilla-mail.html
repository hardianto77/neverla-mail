Guerrilla Mail alternative: Neverla Mail vs Guerrilla Mail

Guerrilla Mail is the elder of the keyless services: a free JSON API since 2011, eleven public domains, choose-your-own addresses and a custom domain for $9.99 a year. Neverla Mail is the same idea with longer retention, an MCP server, attachments to 5 MB and your own domain for nothing. Facts read on Guerrilla Mail’s own pages on 2 September 2026, with the section on where the elder still wins.

All comparisons

In short

  • The closest relatives on this shelf. Both are free, need no account, let you type any address, and expose a keyless API a script can call. The differences are retention, ads, attachments, the MCP server and what a domain of your own costs.
  • One hour versus 5 days. Guerrilla Mail keeps a message for an hour, extendable to two at most, and the address itself never expires. Neverla Mail keeps every message 5 days and the address never expires either.
  • Your own domain: $9.99 a year there, free here. Guerrilla Mail sells it yearly, paid by Bitcoin or PayPal, and lets you make it private. Neverla Mail takes any domain you point at smtp.mail.neverla.web.id for nothing — and keeps it as public as the rest.
  • Pick Guerrilla Mail for eleven domains to choose from, a private custom domain, or an open-source mail server you can run yourself. Pick Neverla Mail for mail that lasts the week, no ads, 5 MB attachments, and an MCP server for agents.

What Guerrilla Mail does well

Guerrilla Mail has been the free, keyless option since before most of this category existed. Four things it does that Neverla Mail does not:

  • Eleven domains. sharklasers.com, grr.la, pokemail.net, spam4.me and seven more. When a sign-up form refuses one, the next is a click away. Neverla Mail has 3 public domains and a paid pool for the forms that refuse all of them.
  • A private custom domain for $9.99 a year. Point a domain you own at Guerrilla Mail and mail to it is “accessible only by you”, or opened to everyone if you prefer. Neverla Mail’s free domain is a catch-all inbox anyone who knows an address can read.
  • A mail server you can run. Go-Guerrilla, the open-source MTA behind the service, is on GitHub. Nothing of Neverla Mail is published as code.
  • Sending, sometimes. The Compose tab can send from a temporary address — with your IP in the headers, and suspended on the day these facts were checked. Neverla Mail cannot send at all, by design.

Where Neverla Mail is different

Neverla Mail keeps what makes Guerrilla Mail good — free, keyless, any address — and changes the four things that make it hard to build on.

  • 5 days, not one hour. A Guerrilla Mail message is gone in sixty minutes, two hours if you extend it twice. A Neverla Mail message stays 5 days on the public domains and on yours, which is long enough for a trial that emails on day three and for a test that runs overnight.
  • A stateless API with a published limit. Guerrilla Mail’s API carries state in a session cookie that expires after about eighteen minutes idle, and its rate limits are deliberately unpublished. Neverla Mail’s is a GET with the address in it, no session, and one read a second per address written down on the limits page.
  • No ads and an MCP server. No AdSense, no Analytics, no third-party script on any page. And an MCP server at https://mail.neverla.web.id/mcp that lets an agent open an inbox and block on wait_for_message for up to 25 seconds — Guerrilla Mail has nothing for agents.
  • Your own domain for nothing. One MX record at smtp.mail.neverla.web.id and every address on the domain is a catch-all inbox, no yearly fee, no payment step. It is public, where Guerrilla Mail’s paid one can be private; the row above says so.

For developers: reading a mailbox

The whole difference in one command. This reads a Neverla Mail mailbox with no header, no key, no account and no session:

shell
$ curl -sG https://mail.neverla.web.id/api/v1/mailbox --data-urlencode "address=anything@mail.neverla.web.id" | jq '{count, alias}'

The Guerrilla Mail equivalent is two calls: get_email_address to open a session and get a cookie, then check_email with that cookie and a sequence number, twenty messages a page. It has worked since 2011 and the site’s own front end runs on it. The difference is the session: a test that forgets the cookie, or waits eighteen minutes, starts over. Neverla Mail’s reference is three stateless endpoints; the Python and Node.js guides have the wait loop.

One habit carries over exactly: on both, an address is a name you typed, so a suite that builds run-{id}@ addresses works unchanged. Watch the retention when you move: an hour is enough for a code, and not enough for a job that retries in the morning.

For AI agents

Guerrilla Mail publishes nothing for agents — no MCP server, no llms.txt — though its keyless API can be called by one that manages the session cookie. Neverla Mail’s server at https://mail.neverla.web.id/mcp gives an agent an inbox with no key: create_inbox, a blocking wait_for_message of up to 25 seconds, read_message.

Email for AI agents covers the four-call loop and the guard rails; the client guide has the configuration for Claude, Cursor and five others.

Switching from Guerrilla Mail

Both are keyless, so the switch is short:

  1. Keep your naming, change the domain. name@sharklasers.com becomes name@mail.neverla.web.id, or any name on a domain of yours with its MX at smtp.mail.neverla.web.id.
  2. Drop the session. Replace get_email_address plus check_email with a GET on /api/v1/mailbox?address=…; there is no cookie to carry and no sequence number. Page with the next cursor if a mailbox is busy.
  3. Remove the extend calls. Nothing here needs extending: 5 days is the window, for every message.
  4. Decide about privacy. If you paid for a private custom domain, know that the same domain here is public; hand out the alias where privacy matters, or stay.

Which one, for what

The honest split:

Pick Neverla Mail when

  • the mail has to live longer than an hour or two;
  • you want no ads, a stateless API with published limits, and an MCP server;
  • you want your own domain as a catch-all inbox for free.

Pick Guerrilla Mail when

  • you want eleven domains to rotate through at sign-up forms;
  • you want a private custom domain for $9.99 a year;
  • you want to run the mail server yourself, or occasionally send from the address.

When to stay with Guerrilla Mail

Three situations where switching would cost you something real:

  • Your custom domain is private and you rely on that. Guerrilla Mail lets you make it “accessible only by you”; Neverla Mail does not, at any price. That is a real difference, not a footnote.
  • You rotate domains to get past blocklists. Eleven public domains beat 3. Neverla Mail’s answer is a paid pool of off-blocklist domains or a domain of your own; if you would rather not do either, stay.
  • You need to send. Even suspended some days, Guerrilla Mail’s Compose exists; Neverla Mail has no sending path and will not add one.

Questions

Is Neverla Mail a Guerrilla Mail alternative?

The nearest one on this shelf: free, keyless, any address, an API a script can call. What changes is retention (5 days instead of one hour), ads (none), attachments (5 MB per message), an MCP server, and a free domain of your own — which is public, where Guerrilla Mail’s paid one can be private.

How long does Guerrilla Mail keep messages?

One hour, in its own words, extendable by an hour at a time to a maximum of two. The address itself never expires. Neverla Mail keeps every message 5 days.

Does Guerrilla Mail have an API?

Yes, a public JSON API documented since 2011, keyless, with state in a session cookie and rate limits it deliberately does not publish. Neverla Mail’s API is keyless and stateless, with one read a second per address written down.

Which one has more domains?

Guerrilla Mail, with eleven public domains to Neverla Mail’s 3. Neverla Mail adds a paid pool of domains kept off the disposable-mail blocklists, and a free domain of your own, which the blocklist guide explains is the durable fix.

Which one works with AI agents?

Neverla Mail runs a free keyless MCP server with a blocking wait_for_message; Guerrilla Mail publishes none. The client guide has the configuration.
