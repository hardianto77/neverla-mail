For developers

An API you can read in a minute

Three endpoints, JSON in and JSON out. No key and no account on public domains — built for the CI job that has to read a signup email.

Everything waiting at an address, newest first. This is the call your test suite polls.

List a mailbox 
$ curl -G https://mail.neverla.web.id/api/v1/mailbox \
  --data-urlencode "address=k7fq2m@mail.neverla.web.id"
Response 
{
  "address": "k7fq2m@mail.neverla.web.id",
  "alias": "hq8kd2m4p7zt@alias-domain.example",
  "count": 1,
  "next": null,
  "messages": [
    {
      "id": "01JR8W2K4Q",
      "from": "no-reply@example.com",
      "subject": "Your verification code",
      "date": "2026-08-04T18:31:07Z",
      "seen": false,
      "attachments": 0,
      "expires_at": "2026-08-09T18:31:07Z"
    }
  ]
}

Headers, the plain-text part, the HTML part and any attachments.

Read a message 
$ curl -G https://mail.neverla.web.id/api/v1/message/01JR8W2K4Q \
  --data-urlencode "mailbox=k7fq2m@mail.neverla.web.id"
Response 
{
  "id": "01JR8W2K4Q",
  "from": "no-reply@example.com",
  "to": "k7fq2m@mail.neverla.web.id",
  "subject": "Your verification code",
  "date": "2026-08-04T18:31:07Z",
  "text": "Your code is 481920. It expires in 10 minutes.",
  "html": null,
  "attachments": []
}

Removes it at once, rather than waiting for the retention window to expire.

Delete a message 
$ curl -X DELETE -G https://mail.neverla.web.id/api/v1/message/01JR8W2K4Q \
  --data-urlencode "mailbox=k7fq2m@mail.neverla.web.id"
Response 
{
  "deleted": true,
  "id": "01JR8W2K4Q"
}

Free: 60 requests a minute and 1,000 a day, one read a second per address. Paid plans: no cap, from $12.99 a month.

Custom domains

Use your own domain, keep it private

One DNS record, and every address on your domain becomes a private mailbox here — nothing to create in advance, and your domain is never listed on this site.

  1. 1

    Add this MX record at your DNS provider

    TypeMX
    Name@
    Priority10
    Value — the part you paste smtp.neverla.web.id

    Delete any other MX record on the domain while you are there — mail can only be delivered to one place, and a leftover record sends part of it somewhere else.

  2. 2

    Send it something

    We look the record up as the message arrives; if it points here, the domain is connected on the spot and that first message is kept — not bounced while something is activated. Nothing to fill in, no key to keep.

  3. 3

    Open any address

    Go to /inbox/anything@yourdomain.com. Every address on the domain works at once, and the same API covers them all — with no key, which also means anyone who knows the address can read it.

FAQ

Questions people actually ask

Is it really free?

Yes. The public addresses, the API and connecting your own domain are free — no account, no card. The free API allows 60 requests a minute and 1,000 a day per IP address, which covers testing and everyday use. A paid plan adds two things: a pool of domains that are not on the disposable-mail blocklists some signup forms check, and an API with no per-minute or daily cap. Everything free stays free whether you take it or not.

Why did a signup form reject my address?

Because the domain is a known disposable one. The public domains here are listed on the public disposable-mail blocklists, and a large share of signup forms check those lists. Changing the part before the @ does not help — it is the domain being refused. Two ways around it: point your own domain at us, which is free and unlimited, or take a paid plan for a pool of domains that are not on those lists, in the inbox on this site and through the API.

Do I need an account?

No. Grab an address and use it — there is nothing to sign up for. A free account is optional: it keeps every inbox you open in one list, one click from reopening, and gives you a free API key.

Can anyone else read my inbox?

Yes — anyone who knows or guesses the address can open it, on a public domain and on your own domain alike. There is no account here, so there is nothing an inbox could be locked to. The difference a domain of your own makes is that its addresses are on a name nobody else is using, rather than on one printed on every page of this site. Never use either for anything you would mind a stranger reading.

How long do messages last?

Every message is deleted 5 days after it arrives. You can also delete one yourself at any time, from the inbox or through the API.

Can I send email from a neverla address?

No. neverla receives only. There is no outbound sending, by design — it is what keeps the service from becoming a spam tool.

Can I use my own domain?

Yes. Add one MX record pointing at smtp.neverla.web.id and every address on that domain starts working. Your domain is never listed publicly.

Are attachments supported?

Yes, up to 5 MB per message. Larger messages are refused by the mail server, so the sender is told immediately rather than left guessing.
